## Navigation

- React Navigation

## State Management

- Redux Toolkit + Redux Persist: For complex, large-scale apps.
- Zustand: Lightweight, scalable state management with less boilerplate.
- Recoil: Great for managing complex shared state without Redux’s boilerplate.
- React Query / TanStack Query: For server-state management (API caching, pagination, background sync).

## Networking

- Axios or Fetch API for HTTP requests.
- React Query / TanStack Query for API handling, caching, retries, and synchronization.

## UI Components

- NativeBase or React Native Paper for UI libraries with pre-built components.
- Shadcn/ui (React Native version): Clean, modern components (check if stable for RN when you start). Lottie for animations.
- React Native Reanimated for performant animations.

## Forms and Validation

- React Hook Form
- Yup or Zod for schema validation.

## Push Notifications

- Firebase Cloud Messaging (FCM) with React Native Firebase.
- OneSignal: Easy multi-platform support.

## Local Storage

- AsyncStorage (Basic local storage)
- MMKV Storage (Fast, recommended for performance-critical apps)
- SQLite (For structured offline data)

## Development Tools

- Expo: Faster development, great for prototyping. Bare workflow for custom native modules.
- EAS Build: If you use Expo, this is now the go-to cloud build tool.
- Reactotron: For state, API, and Redux debugging.
- Flipper: Recommended for native debugging.
